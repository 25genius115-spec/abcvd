친환경 제품 추천 서비스 — 공유용 프로젝트

프로젝트 코드, 정원 이미지, 탄소량 참고 자료와 최종 발표자료를 담았습니다.
API 키, 기존 DB와 백업, 사용자·구매·인증 기록, HTTPS 인증서와 개인 키, 가상환경은 제외했습니다.
새 DB는 FastAPI를 처음 실행할 때 자동 생성됩니다. 기존 계정은 포함되어 있지 않으므로 회원가입 후 사용하세요.

1. 압축을 풀고 프로젝트 폴더에서 터미널 열기
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt -r backend/requirements.txt

2. 같은 터미널에서 본인의 API 키 설정 후 서버 실행
export EXA_API_KEY="본인의 Exa API 키"
export GEMINI_API_KEY="본인의 Gemini API 키"
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000

3. 새 터미널을 열고 같은 프로젝트 폴더에서 화면 실행
source .venv/bin/activate
python -m streamlit run streamlit_app.py --server.address 127.0.0.1 --server.port 8501

4. 브라우저에서 http://127.0.0.1:8501 접속
두 서버 터미널은 켜 둡니다. 위 명령은 같은 컴퓨터에서만 접속합니다.
Gemini 모델 접근 권한은 API 프로젝트에 따라 다르며 backend/config.py의 환경변수로 변경할 수 있습니다.
발표자료는 발표자료/ 폴더에 있습니다. 화면 사진 삽입 자리는 직접 채우면 됩니다.
자세한 내용은 README.md를 참고하세요.
